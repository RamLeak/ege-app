## Если что-то пойдёт не так

**Симптом:** APK не устанавливается на Samsung.
**Решение:** скорее всего, нужно разрешить Telegram'у установку из неизвестных источников (Настройки → Безопасность → Установка неизвестных приложений → Telegram → Разрешить).

**Симптом:** Приложение крашится при запуске.
**Решение:** скрин экрана с ошибкой → мне. Скорее всего Room не нашёл corpus.db. Чиним.

**Симптом:** Долго грузится первый раз.
**Норма:** при первом запуске Room копирует corpus.db из assets в внутреннюю память. 192 MB. На Samsung Galaxy это ~5-10 секунд. Дальше — мгновенно.

**Симптом:** Claude Code пишет что-то не по DESIGN_SPEC.md.
**Реакция:** в Claude Code: «Stop. Открой DESIGN_SPEC.md секцию X, перечитай, переделай.»
