# DESIGN_SPEC.md — UI/UX Specification for ege-app

> Этот файл — **обязательная инструкция** для построения UI в Фазе 2 и далее. Claude Code должен следовать ему буквально, не отклоняясь без явного согласия пользователя.
>
> Прочитан Claude Code в начале Фазы 2 (Android MVP).

---

## 1. Общая философия

**Apple-стиль на Android.** Это не значит «копируем iOS» — это означает Material 3 с кастомной темой, реализующей принципы iOS-дизайна:

- Большие отступы и много воздуха.
- Закруглённые углы 16-24dp.
- Мягкие тени с большим blur (16-24dp, opacity 8-12%).
- Spring-анимации (`spring(dampingRatio = 0.7, stiffness = Spring.StiffnessMedium)`).
- Минимум границ-рамок — разделение через тени и фоны.
- 2-3 акцентных цвета максимум.
- Системный шрифт крупнее обычного (16-17sp базовый).

**Ключевой принцип:** избегаем визуального шума. Лучше пустое место, чем лишний элемент.

## 4. Анимации

Все анимации — **spring**, не linear/ease.

- Нажатие на карточку: `scale 0.97` → возврат с пружинной отдачей.
- Открытие экрана: slide справа, spring.
- Раскрытие решения: rounded reveal сверху вниз, spring.
- Появление «правильно/неверно»: fade + slide снизу.
- Свайп между задачами: дуговая анимация, не линейная.
- Pull-to-refresh: spring-bounce на главной.

Кодовый пример: `animationSpec = spring(dampingRatio = 0.7f, stiffness = Spring.StiffnessMedium)`.

## 7. Поведение взаимодействий

### 7.1 Кнопки

**«Проверить»** — основная кнопка, заполненная акцентным цветом, full-width внутри секции.

**«Решение»** — выпадающий блок, кнопка тапа `▼ Раскрыть`.

**«📋 Правило»** — bottom sheet появляется снизу, в нём текст правила.

**«🤖 ИИ»** — **disabled до первой попытки** (Safety Rule #2). При клике сразу открывается чат-окно для ввода вопроса.

**«⭐»** — золотая если уже добавлено, серая если нет. Тап = переключение.

### 7.2 Жесты

- **Свайп влево** на экране задачи → следующая задача (без статистики, если ответа не было).
- **Свайп вправо** НЕ использовать (зарезервирован системным «назад» Android).
- **Долгий тап** на задаче в списке → меню (избранное, копировать ID).
- **Pull-to-refresh** на главной → обновить предиктор и радар.
- **Свайп вниз в bottom sheet** → закрыть.
- **Тап на формулу** → раскрытие на полный экран (для сложных).

### 7.3 ИИ — модель и стоимость

**По умолчанию:** `claude-haiku-4-5-20251001` (дёшево).
**Опционально:** `claude-sonnet-4-7` (флаг «Подробно» в чате).

**Кеш ответов:** `prompt_hash = sha256(problem_id + normalize(question))`. Повторный вопрос → ответ из БД, токены не тратятся.

**Hard limit:** $15/мес из console.anthropic.com. В Профиле — индикатор «Потрачено в этом месяце: $X.YZ / $15».

### 7.4 Проверка ответа

**Правильно:**
1. Зелёная плашка «✅ Правильно».
2. Streak обновляется если применимо.
3. Решение можно открыть тапом (НЕ автоматически).

**Неверно:**
1. Красная плашка «❌ Неверно (правильный: ...)».
2. Автоматически добавляется в журнал ошибок.
3. Кнопка ИИ активируется и подсвечивается.
4. Решение открывается **согласно настройке в Профиле**:
   - Опция А: автоматически.
   - Опция Б: по кнопке «Показать решение».

**Не ввёл ответ:**
- Можно тапнуть «Показать решение».

## 9. Пробники

### Логика расписания

**App предлагает каждый месяц** — push-уведомление + плашка на главном экране «Время для пробника». Это **рекомендация**, не принуждение.

**Пользователь также может запустить пробник в любой момент** через «Решать» → «🧪 Пробник» (отдельная кнопка добавляется в «Быстрый старт» после готовности фичи в Фазе 4).

### Структура пробника

- Генератор варианта: по одной задаче каждого типа №1-19 (для математики) или №1-27 (для русского).
- **Таймер:** часы и минуты согласно реальному ЕГЭ:
  - Математика профильная: 235 минут (3ч 55мин).
  - Русский язык: 210 минут (3ч 30мин).
- **AI и подсказки заблокированы** во время пробника (симуляция ЕГЭ).
- **Можно прервать** с сохранением частичного результата.

### Результат пробника

После завершения:
- Первичный балл (количество правильных ответов).
- Вторичный балл (по таблице ФИПИ).
- Разбор ошибок (какие типы провалены).
- Сравнение с предыдущими пробниками (график тренда).

### Импорт КИМ ФИПИ

Дополнительно — возможность импортировать **открытый вариант КИМ ФИПИ-2026** как «официальный пробник». Структура: те же 19/27 задач, но из реального варианта ЕГЭ, не сгенерированные.

Эти типы задач на sdamgia **не имеют исходного текста** (известное ограничение корпуса). В UI:

## 11. Чего НЕ делать

- ❌ Кнопка «Не знаю» — портит визуал, используем свайп вместо.
- ❌ Жёлтые/красные предупреждения на главном экране — мотивирующая среда, не «у тебя плохие результаты».
- ❌ Бейджи и уведомления на иконке app («у тебя 47 ошибок») — давит на психику.
- ❌ Соревновательные элементы (рейтинги, лидерборды) — это твой личный проект.
- ❌ Реклама и платные фичи — приложение полностью бесплатное и приватное.
- ❌ Аналитика / телеметрия / трекинг — никаких сторонних SDK.
- ❌ Социальный шеринг — не публикуем результаты.

## 12. Технические аспекты UI

### Compose-стек

- `androidx.compose.material3` — база.
- `androidx.compose.animation` — анимации.
- `androidx.navigation:navigation-compose` — навигация.
- `io.coil-kt:coil-compose` — асинхронные SVG из БД (формулы и иллюстрации).
- `androidx.compose.foundation:foundation` — жесты.

### Рендер формул

- **НЕ MathJax / WebView.** Это был старый план, отменён после Stage 0.
- **SVG напрямую через Coil** — `AsyncImage(model = svgFile)`. SVG лежат в `assets/_formulas/{hash}.svg`.
- При расхождении тёмной/светлой темы — два варианта SVG или CSS-инверсия (определить в Фазе 2).

### Минимальный Android SDK

- minSdk 26 (Android 8.0) — покрывает ~95% устройств в Германии.
- targetSdk актуальный (на момент Фазы 2 — Android 14/15).

### Производительность

- Список задач — `LazyColumn` с ключами по ID.
- Запросы к БД — через Room с suspend-функциями.
- Формулы — кешируются Coil автоматически, повторный рендер мгновенный.
